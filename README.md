## 📌 Sobre o repositório

Este repositório reúne os códigos-fonte, documentos e implementações desenvolvidos nas avaliações da disciplina **DIW**.

O objetivo é documentar a evolução prática dos conhecimentos em desenvolvimento Front-end, utilizando diferentes tecnologias e ferramentas do ecossistema web.

## 🎯 Objetivos de aprendizagem

- Desenvolver interfaces web utilizando HTML e CSS.
- Implementar funcionalidades com JavaScript.
- Construir layouts responsivos com Bootstrap.
- Manipular dados utilizando JSON.
- Consumir e simular APIs REST.
- Aplicar boas práticas de organização e desenvolvimento de código.
